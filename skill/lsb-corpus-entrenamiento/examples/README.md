# Ejemplos de glosas

ejemplos_traduccion_glosa_a_espanol.json contiene ocho ejemplos ilustrativos heredados de la rama Apaza. No se acompañan de registros de revisión por una persona competente en LSB; por tanto, son fixtures provisionales para explorar el formato, no traducciones aprobadas ni material de entrenamiento.

No uses estos ejemplos para evaluar calidad lingüística o afirmar que el traductor funciona. Antes de conservarlos como casos de referencia, registra fuente, contexto, variante, responsable de revisión y estado de aprobación por ejemplo.
